# Icon sources

The following local WebP files were adapted into a consistent 200×200 presentation with transparent backgrounds and a small gray offset shadow.

## Simple Icons

Source: https://github.com/simple-icons/simple-icons\
License: CC0-1.0

- `TS.webp` — TypeScript
- `Vue.webp` — Vue.js
- `Nuxt.webp` — Nuxt
- `Nextjs.webp` — Next.js
- `Python.webp` — Python
- `Docker.webp` — Docker
- `ArchLinux.webp` — Arch Linux

The source SVG files were downloaded from the versioned Simple Icons v16 CDN.

## Lucide

Source: https://github.com/lucide-icons/lucide\
License: ISC

- `Server.webp` — Server
- `Tool.webp` — Wrench

The source SVG files came from `lucide-static@0.468.0`.

## Taro

Source: https://github.com/NervJS/taro\
License: MIT

- `Taro.webp` — adapted from the Taro mark used in the official repository and normalized as a blue application badge.

## DCloud

Source: https://web-assets.dcloud.net.cn/hello-uni-app-x/uni-app.png\
Project repository: https://github.com/dcloudio/uni-app\
Repository license: Apache-2.0

- `Uniapp.webp` — adapted from the uni-app mark published on DCloud's official asset domain, with the inner mark changed to white for contrast on the dark footer.

## Existing project asset

- `CSS.webp` — local alias of the existing `CSS3.webp` asset so database icon names resolve without changing historical data.
